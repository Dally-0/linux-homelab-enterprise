\section{Resumen Ejecutivo de Vulnerabilidades Encontradas}

\section{División y Análisis Pormenorizado de Cada Vulnerabilidad}

En concordancia con los resultados empíricos, a continuación se desglosa individualmente cada vulnerabilidad identificada, detallando su caracterización técnica, vector de ataque, puntuación CVSS v3.1 y el impacto potencial sobre la infraestructura organizacional.

% -----------------------------------------------------------------------------
\subsection{VULN-01: Intercambio Criptográfico Anónimo Diffie-Hellman en SMTP y Submission}
% -----------------------------------------------------------------------------

\begin{itemize}
  \item \textbf{Servicios Afectados:} \texttt{25/tcp} (SMTP) y \texttt{587/tcp} (Submission).
  \item \textbf{Script Detector NSE:} \texttt{ssl-dh-params}.
  \item \textbf{Clasificación CWE:} CWE-327 (\textit{Use of a Broken or Risky Cryptographic Algorithm}).
  \item \textbf{Detalle Técnico del Hallazgo:} El servidor Postfix negocia suites de cifrado anónimas (\texttt{aNULL}):
    \begin{enumerate}
      \item \texttt{TLS\_DH\_anon\_WITH\_AES\_256\_CBC\_SHA256} (Grupo Oakley 15, módulo de 3072 bits).
      \item \texttt{TLS\_DH\_anon\_WITH\_AES\_128\_CBC\_SHA} (Grupo Oakley 2, módulo débil de 1024 bits).
    \end{enumerate}
  \item \textbf{Puntuación CVSS v3.1:}
    \begin{itemize}
      \item \textbf{Vector:} \texttt{CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:N}
      \item \textbf{Puntaje Base:} \textbf{7.4 (Severidad Alta)}
    \end{itemize}
  \item \textbf{Mecanismo de Explotación e Impacto:} El intercambio Diffie-Hellman anónimo genera llaves efímeras sin exigir ni validar un certificado digital que certifique la autenticidad del servidor. Por consiguiente, un atacante posicionado en el mismo segmento de red conmutado (mediante envenenamiento ARP o suplantación de gateway) puede ejecutar un ataque activo \textbf{Man-in-the-Middle (MitM)}. El adversario establece un canal TLS por separado con el cliente y con el servidor, interceptando, descifrando y manipulando en tiempo real las comunicaciones y credenciales de correo electrónico corporativo sin disparar advertencias visuales de certificado inválido en el cliente.
\end{itemize}

% -----------------------------------------------------------------------------
\subsection{VULN-02: Denegación de Servicio por Solicitud de Múltiples Rangos de Bytes (CVE-2011-3192)}
% -----------------------------------------------------------------------------

\begin{itemize}
  \item \textbf{Servicios Afectados:} \texttt{80/tcp} (HTTP) y \texttt{443/tcp} (HTTPS).
  \item \textbf{Script Detector NSE:} \texttt{http-vuln-cve2011-3192} (Estado: \texttt{VULNERABLE}, Identificadores: \texttt{CVE-2011-3192}, \texttt{BID:49303}).
  \item \textbf{Clasificación CWE:} CWE-400 (\textit{Uncontrolled Resource Consumption}).
  \item \textbf{Detalle Técnico del Hallazgo:} El servidor web responde de manera permisiva ante peticiones HTTP con cabeceras de rango superpuestas (\textit{overlapping byte-ranges}) como \texttt{Range: bytes=0-,5-0,5-1,5-2...}.
  \item \textbf{Puntuación CVSS v3.1:}
    \begin{itemize}
      \item \textbf{Vector:} \texttt{CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H}
      \item \textbf{Puntaje Base:} \textbf{7.5 (Severidad Alta)}
    \end{itemize}
  \item \textbf{Mecanismo de Explotación e Impacto:} Al recibir una única petición con decenas o cientos de rangos fragmentados, el servidor web asigna memoria y tiempo de CPU desproporcionado para fraccionar y empaquetar la respuesta en formato multiparte (\texttt{multipart/byteranges}). Un solo equipo atacante enviando un flujo moderado de estas peticiones puede agotar completamente la memoria RAM disponible del servidor web, provocando la caída por \textit{Out-Of-Memory} (OOM Killer) e interrumpiendo el acceso de los clientes legítimos a la plataforma bancaria.
\end{itemize}

% -----------------------------------------------------------------------------
\subsection{VULN-03: Método y Modo de Depuración Activo en Webmail (http-aspnet-debug)}
% -----------------------------------------------------------------------------

\begin{itemize}
  \item \textbf{Servicio Afectado:} \texttt{8080/tcp} (RoundCube Webmail / HTTP-Proxy).
  \item \textbf{Script Detector NSE:} \texttt{http-aspnet-debug} (Reporte: \texttt{status: DEBUG is enabled}).
  \item \textbf{Clasificación CWE:} CWE-489 (\textit{Active Debug Code}).
  \item \textbf{Detalle Técnico del Hallazgo:} El servicio web responde afirmativamente a solicitudes con el método HTTP no estándar \texttt{DEBUG}, típicamente empleado en fases de desarrollo para depuración remota de aplicaciones.
  \item \textbf{Puntuación CVSS v3.1:}
    \begin{itemize}
      \item \textbf{Vector:} \texttt{CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N}
      \item \textbf{Puntaje Base:} \textbf{5.3 (Severidad Media)}
    \end{itemize}
  \item \textbf{Mecanismo de Explotación e Impacto:} Permitir métodos o modos de depuración activos en entornos de producción expone a la organización a la divulgación no intencionada de trazas de ejecución de código, rutas físicas del servidor, versiones exactas de librerías y estructuras de variables internas de sesión, facilitando el reconocimiento previo para ataques dirigidos más avanzados.
\end{itemize}

% -----------------------------------------------------------------------------
\subsection{VULN-04: Exposición Pública del Puerto PostgreSQL (5432/tcp)}
% -----------------------------------------------------------------------------

\begin{itemize}
  \item \textbf{Servicio Afectado:} \texttt{5432/tcp} (PostgreSQL Database Server).
  \item \textbf{Clasificación CWE:} CWE-284 (\textit{Improper Access Control}) y CWE-200 (\textit{Information Exposure}).
  \item \textbf{Detalle Técnico del Hallazgo:} El contenedor de la base de datos central enruta su socket de escucha directamente hacia todas las interfaces de red del host (\texttt{0.0.0.0:5432}), permitiendo conexiones TCP desde cualquier equipo de la red externa sin restricción previa a nivel de cortafuegos.
  \item \textbf{Puntuación CVSS v3.1:}
    \begin{itemize}
      \item \textbf{Vector:} \texttt{CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N}
      \item \textbf{Puntaje Base:} \textbf{7.5 (Severidad Alta)}
    \end{itemize}
  \item \textbf{Mecanismo de Explotación e Impacto:} La exposición innecesaria de la base de datos permite que adversarios realicen ataques automatizados de diccionario y fuerza bruta contra cuentas privilegiadas (\texttt{postgres}, \texttt{tso\_user}), o exploten vulnerabilidades de autenticación o de desbordamiento en el protocolo nativo de PostgreSQL, con el riesgo potencial de exfiltración masiva de datos bancarios.
\end{itemize}

% -----------------------------------------------------------------------------
\subsection{VULN-05: Exposición de Servicios Administrativos y Web en Texto Plano (HTTP)}
% -----------------------------------------------------------------------------

\begin{itemize}
  \item \textbf{Servicios Afectados:} \texttt{3000/tcp} (Grafana), \texttt{8000/tcp} (Portainer), \texttt{8082/tcp} (Filemanager), \texttt{8085/tcp} (Uyuni Way Web).
  \item \textbf{Clasificación CWE:} CWE-319 (\textit{Cleartext Transmission of Sensitive Information}).
  \item \textbf{Detalle Técnico del Hallazgo:} Diversos paneles de control y aplicaciones web operan en puertos alternativos transmitiendo el tráfico HTTP sin envoltorio TLS.
  \item \textbf{Puntuación CVSS v3.1:}
    \begin{itemize}
      \item \textbf{Vector:} \texttt{CVSS:3.1/AV:N/AC:H/PR:N/UI:R/S:U/C:H/I:H/A:N}
      \item \textbf{Puntaje Base:} \textbf{7.4 (Severidad Alta)}
    \end{itemize}
  \item \textbf{Mecanismo de Explotación e Impacto:} La falta de cifrado en la capa de transporte permite a atacantes locales con herramientas como Wireshark o \textit{tcpdump} interceptar contraseñas administrativas, tokens de sesión y datos confidenciales transmitidos durante la navegación de los operadores.
\end{itemize}

% -----------------------------------------------------------------------------
\subsection{DEF-01: Neutralización Activa de Inyección SQL y Exploits por WAF/IPS (Script Failed)}
% -----------------------------------------------------------------------------

\begin{itemize}
  \item \textbf{Evidencia en Escaneo:}
    \begin{itemize}
      \item \texttt{http-vuln-cve2017-1001000: ERROR: Script execution failed} (Puertos 80, 443, 8080).
      \item \texttt{http-sql-injection: ERROR: Script execution failed} (Puerto 8080).
      \item \texttt{http-stored-xss / http-csrf / http-dombased-xss: Couldn't find vulnerabilities}.
    \end{itemize}
  \item \textbf{Evaluación Defensiva:} Este comportamiento en los scripts de Nmap confirma la eficacia de las capas defensivas desplegadas:
    \begin{enumerate}
      \item \textbf{Firewall Web (WAF Nginx):} Detecta los patrones de inyección SQL (\texttt{UNION SELECT}, \texttt{' OR '1'='1}) en los argumentos y corta la transacción retornando un código \texttt{403 Forbidden}.
      \item \textbf{Suricata IPS en Línea:} Al identificar firmas de exploits conocidos (\texttt{CVE-2017-1001000}), las reglas de prevención de intrusiones ejecutan acciones de descarte inmediato de paquetes (\texttt{DROP}), provocando que el script NSE experimente un cierre abrupto de socket y reporte error de ejecución.
    \end{enumerate}
\end{itemize}
